THE LIFECYCLE — دورة العمل

تشريح دورة الصفقة:
ثماني مراحل، وفرصة أتمتة في كل مرحلة

مشيّنا رحلة الصفقة خطوة خطوة، من أول ما يصل العقار للمكتب إلى ما بعد البيع. تحت كل مرحلة كتبنا وش يقدر يمشي تلقائياً بدون تدخل يدوي، وهذا هو الفرق بين إدارة ورقية ونظام شغال.

17 · جديد

بوابة المالك

تطبيق/صفحة خاصة يرى فيها المالك عقاراته: المشاهدات، العروض، حالة التسويق — ويوافق أو يرفض العروض بضغطة. تقلل الاتصالات الاستفسارية وتزيد ثقة المالك.

18 · جديد

التقييم السعري الذكي

تحليل تلقائي لأسعار المناطقة والمقارنات من داخل بيانات النظام والسوق، مع نطاق سعر مقترح ومبررات — أداة إقناع للمالك وللعميل.

19 · جديد

التواقيع والتفويضات الرقمية

توقيع اتفاقيات الوساطة والتفويضات إلكترونيًا مع أثر تحقق، بدل الورق والتصوير.

20 · جديد

الفوترة الإلكترونية

فواتير عمولات متوافقة مع متطلبات الفاتورة الإلكترونية (فاتورة/فرقية)، وربطها بالتحصيل.

21 · جديد

الخرائط والمواقع GIS

عرض العقارات على الخريطة، تحليل المناطق الساخنة، وحساب مسارات المعاينات لضغط وقت الوسيط.

22 · جديد

تطبيق الوسطاء الميداني

واجهة جوال سريعة للوسيط في الميدان: معاينات اليوم، تسجيل نتيجة الزيارة، رفع صور فوري، وتنبيهات لحظية.

ثمانية مساعدين… يعملون تحت إشراف فريق المهوس

الذكاء الاصطناعي هنا مو شارة تسويقية. كل مساعد مربوط بمهمة يومية حقيقية، عمله يقترح ويساعد، والقرار الأخير يبقى دائماً بيد موظف المكتب.

ALMAHOUS / AI AGENTS
AGENT 01

مساعد الإعلان

يولّد العنوان والوصف والوسوم بأسلوب المكتب، ويحسّن النصوص حسب أداء الإعلانات المشابهة.

AGENT 02

مساعد المبيعات

يقترح ردّ الوسيط وخطوة المتابعة التالية بناءً على سياق المحادثة وتصنيف جدية العميل.

AGENT 03

مساعد المطابقة

يفسّر بلغة طبيعية لماذا يتوافق عقار ما مع طلب العميل — حجة جاهزة أمام العميل.

AGENT 04

مساعد المستندات

يستخرج بيانات سند الملكية والتفويض من الصور، ويحدد النواقص قبل المراجعة البشرية.

AGENT 05

مساعد الإدارة

يقرأ مؤشرات الأسبوع ويلخّص أسباب التغير: لماذا تراجعت المعاينات؟ أي قناة تستحق زيادة الاستثمار؟

AGENT 06

مساعد استقبال العملاء

يجيب على الأسئلة الأولية حول العقارات المتاحة، ويحوّل الجادّين للوسيط المناسب مع ملخص المحادثة.

AGENT 07 · جديد

مساعد التسعير

يحلّل الصفقات والقوائم المشابهة ويقترح نطاقًا سعريًا مبررًا — يُستخدم في إقناع الملاك المبالغين بالسعر.

AGENT 08 · جديد

حارس المخزون

يراقب إعلانات ركِدت بلا استفسارات، وتفويضات على وشك الانتهاء، وعقارات مكررة — ويتدخل قبل أن تصبح مشكلة.

مثال واقعي واحد: يجيك استفسار واتساب الساعة ١١ الليل. المساعد الأولي يجاوب ويعرف الجدية والميزانية، ومحرك المطابقة يجهز ثلاثة عقارات مناسبة. الصبح الساعة ٨ يستلم الوسيط عميلاً مؤهلاً بملف كامل وموعد جاهز للعرض. صار عندك استقبال ٢٤ ساعة، بدون موظف مناوبة.

07
AUTOMATION ENGINE — محرك الأتمتة

مكتبة قواعد تشغيلية تنمو مع نمو المكتب

ALMAHOUS / AUTOMATION
TRIGGER · عقار

دورة حياة العقار

عقار جديد → فحص بيانات → اعتماد → توليد إعلان → تجهيز قائمة العملاء المرشحين → إشعار الوسيط المسؤول.

TRIGGER · عميل

دورة استقبال العميل

استفسار جديد → كشف تكرار → توزيع آلي حسب المنطقة والعبء → مهمة متابعة أولى → تنبيه إن لم يُرد الوسيط خلال ٣٠ دقيقة → تصعيد للمشرف.

TRIGGER · معاينة

دورة المعاينة

حجز → تأكيد فوري → تذكير قبل ساعتين → بعد الموعد: استبيان رأي العميل + مهمة تسجيل نتيجة الزيارة للوسيط.

TRIGGER · صفقة

دورة الإغلاق والعمولة

قبول عرض → قائمة إغلاق رقمية → احتساب الحصص آليًا → فاتورة إلكترونية → تحديث حالة العقار → طلب سحب الإعلانات المنتهية.

TRIGGER · تسويق

صيانة الإعلانات

إعلان بلا استفسارات ١٤ يومًا → اقتراح تحديث الصور/السعر · تفويض ينتهي خلال ٧ أيام → تنبيه المالك عبر البوابة لتجديده.

TRIGGER · مالك

تقرير المالك الدوري

أسبوعيًا/شهريًا: مشاهدات الإعلان، الاستفسارات، العروض، وملاحظات الوسيط — يصل للمالك آليًا دون طلب.
